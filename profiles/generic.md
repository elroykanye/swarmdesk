# Profile: generic

The defaults. Copy this to the board's PROFILE.md and edit it; every line is yours to change.

## Needs the manager's yes

- Any write to shared state: databases, caches, clusters, queues, identity, secrets, deployment tools.
- Any merge into a shared branch.
- Any message, comment or email to a person outside the board.
- Anything that spends money or changes access.

## Needs the human's own hand

- A click in the human's own window, a credential only the human holds, a message from the human's account.

## Conventions

- Version and commit conventions: those of the project's repository.
- Tests run where the project normally runs them. Heavy runs go to the runner, if the board has one.

## Reaching the human

The manager keeps `for-human.md` and, if its harness can, asks in its own window.
